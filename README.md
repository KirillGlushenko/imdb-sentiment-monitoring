
# IMDb Sentiment Monitoring & Alerting

Python-проект для мониторинга тональности отзывов IMDb с автоматическими уведомлениями в Telegram и Email.

## Возможности

- Загрузка исходного датасета IMDb из CSV или ZIP.
- Очистка HTML-тегов и лишних пробелов.
- Проверка меток `positive` и `negative`.
- Удаление дубликатов отзывов.
- Сохранение обработанного датасета.
- Анализ отзывов партиями.
- Расчёт доли негативных отзывов.
- Отправка уведомлений при превышении порога 40%.
- Отправка сообщений через Telegram-бота.
- Формирование Email-уведомлений.
- Поддержка тестового и SMTP-режимов Email.
- Запись событий в журнал.
- Автоматическое тестирование.

## Подготовка данных

Для проекта используется датасет IMDb с платформы Kaggle.

Предполагаемый источник:

[IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

Для воспроизведения анализа:

1. Перейти по ссылке и скачать датасет.
2. Поместить ZIP-архив в папку `data/raw/`.
3. Переименовать архив в `archive.zip`.
4. Запустить команду:

```powershell
python prepare_data.py
```

После обработки данные сохраняются в:

`data/processed/imdb_clean.csv`

В ходе подготовки выполняются:
- очистка HTML-тегов;
- нормализация пробелов;
- проверка меток тональности;
- удаление дубликатов;
- расчёт длины отзывов.

В демонстрационном запуске после обработки осталось 49 578 отзывов.

Исходный датасет не включён в GitHub-репозиторий.

## Настройка уведомлений

Создать файл `.env` в корне проекта. Можно использовать `.env.example` как шаблон.

Для Telegram указать:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

Для Email:

```env
EMAIL_MODE=test
SMTP_HOST=
SMTP_PORT=465
SMTP_USER=
SMTP_PASSWORD=
EMAIL_FROM=
EMAIL_TO=
```

### Telegram

Для отправки уведомлений используется Telegram Bot API.

При превышении установленного порога программа отправляет сообщение в указанный Telegram-чат.

### Email

Предусмотрены два режима:

- `test` — письмо формируется и выводится в терминал без фактической отправки.
- `smtp` — отправка через почтовый сервер при наличии необходимых настроек.

В демонстрационном запуске используется режим `test`.

Файл `.env` содержит конфиденциальные настройки и исключён из Git с помощью `.gitignore`.

## Запуск мониторинга

В терминале выполнить:

```powershell
python .\src\monitor.py
```

В текущей демонстрационной конфигурации программа:

1. Загружает обработанные отзывы IMDb.
2. Анализирует 5 партий по 100 отзывов.
3. Рассчитывает количество положительных и отрицательных отзывов.
4. Определяет процент негативных отзывов.
5. Сравнивает его с установленным порогом 40%.
6. При превышении порога формирует предупреждение.
7. Отправляет Telegram-уведомление.
8. Формирует Email-уведомление.
9. Записывает результаты мониторинга в журнал.

Условие срабатывания:

```python
negative_percent > 40.0
```

Предупреждение формируется, когда доля негативных отзывов строго превышает 40%.

## Логирование

Информация о работе программы записывается в файл:

`logs/monitor.log`

Журнал содержит:

- время запуска мониторинга;
- количество загруженных отзывов;
- результаты анализа каждой партии;
- предупреждения о превышении порога;
- информацию о завершении программы;
- ошибки обработки данных и мониторинга.

Для просмотра последних записей в Windows PowerShell:

```powershell
Get-Content -Encoding UTF8 .\logs\monitor.log -Tail 15
```

## Автоматические тесты

Для тестирования используется стандартная библиотека Python `unittest`.

Запуск тестов:

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

Реализованы четыре автоматических теста:

1. `test_clean_review` — проверка очистки текста от HTML-тегов и лишних пробелов.
2. `test_remove_duplicates` — проверка удаления повторяющихся отзывов.
3. `test_negative_alert` — проверка формирования предупреждения при превышении порога негатива.
4. `test_no_alert` — проверка отсутствия предупреждения при нормальной доле негатива.

При тестировании функции отправки Telegram и Email подменяются mock-объектами.

Благодаря этому тесты проверяют логику уведомлений без реальной отправки сообщений.

Результат локального тестирования:

```text
Ran 4 tests in 0.031s

OK
```

Все четыре теста успешно пройдены.

## Ограничения проекта

Исходный датасет не содержит времени публикации отзывов.

Поэтому мониторинг имитирует поступление последовательных партий данных, а не получает отзывы IMDb в реальном времени.

Для определения тональности используются готовые метки `positive` и `negative` из датасета.

Отдельная модель машинного обучения для классификации текста не обучается.

SMTP-отправка реализована в коде, однако без настройки почтового сервера и учётных данных фактическая отправка писем не проверялась.
