
# IMDb Sentiment Monitoring & Alerting

Python-проект для мониторинга тональности отзывов IMDb с автоматическими уведомлениями в Telegram и Email.

## Возможности

- Загрузка исходного датасета IMDb из CSV или ZIP.
- Очистка HTML-тегов и лишних пробелов.
- Проверка меток positive и negative.
- Удаление дубликатов отзывов.
- Сохранение обработанного датасета.
- Анализ отзывов партиями.
- Расчёт доли негативных отзывов.
- Отправка уведомлений при превышении порога 40%.
- Отправка сообщений через Telegram-бота.
- Формирование Email-уведомлений.
- Поддержка тестового и SMTP-режимов Email.
- Запись событий в журнал.
- Автоматическое тестирование.

## Установка

Требуется Python 3.10 или новее.

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
pip install -r requirements.txt
```

## Подготовка данных

Поместить исходный архив `archive.zip` в папку `data/raw/`.

Выполнить:

```powershell
python prepare_data.py
```

Обработанные отзывы сохраняются в:

`data/processed/imdb_clean.csv`

В ходе подготовки выполняются очистка текста, проверка меток и удаление дубликатов.

## Настройка уведомлений

Создать файл `.env` в корне проекта.

Для Telegram указать:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

Для Email:

```env
EMAIL_MODE=test
SMTP_HOST=
SMTP_PORT=465
SMTP_USER=
SMTP_PASSWORD=
EMAIL_FROM=
EMAIL_TO=
```

В режиме `test` письма отображаются в терминале и не отправляются.

Режим `smtp` предусматривает реальную отправку через почтовый сервер после заполнения настроек.

Файл `.env` содержит конфиденциальные данные и не должен публиковаться в Git.

## Запуск мониторинга

```powershell
python .\src\monitor.py
```

В текущей демонстрационной конфигурации программа:

1. Загружает обработанные отзывы IMDb.
2. Анализирует 5 партий по 100 отзывов.
3. Рассчитывает процент негативных отзывов.
4. Сравнивает результат с порогом 40%.
5. При превышении порога формирует предупреждение.
6. Отправляет Telegram-уведомление.
7. Формирует Email-уведомление.
8. Записывает результаты в журнал.

Условие срабатывания:

```python
negative_percent > 40.0
```

## Логирование

Информация о работе программы записывается в:

`logs/monitor.log`

Журнал содержит:

- время запуска;
- количество загруженных отзывов;
- результаты анализа партий;
- предупреждения о превышении порога;
- информацию о завершении мониторинга;
- ошибки мониторинга.

Просмотреть последние записи в PowerShell:

```powershell
Get-Content -Encoding UTF8 .\logs\monitor.log -Tail 15
```

## Автоматические тесты

Для тестирования используется стандартная библиотека Python `unittest`.

Запуск:

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

Реализованы четыре теста:

1. `test_clean_review` — проверка очистки текста.
2. `test_remove_duplicates` — проверка удаления дубликатов.
3. `test_negative_alert` — проверка срабатывания предупреждения.
4. `test_no_alert` — проверка отсутствия предупреждения при нормальной доле негатива.

В тестах функции отправки уведомлений подменяются mock-объектами, поэтому реальные сообщения в Telegram не отправляются.

Все четыре теста успешно выполнялись при локальной проверке.

## Ограничения

Исходный датасет не содержит времени публикации отзывов.

Поэтому мониторинг имитирует поступление последовательных партий данных, а не получает новые отзывы IMDb в реальном времени.

Для анализа используются готовые метки `positive` и `negative` из датасета. Отдельная модель машинного обучения для определения тональности не обучается.

SMTP-отправка реализована в коде, однако без почтовых учётных данных её реальная работа не проверялась.

## Итог

Проект демонстрирует полный цикл обработки данных: загрузку, очистку, анализ, проверку пороговых значений, формирование уведомлений и ведение журнала событий.

Реализованы автоматические тесты основных функций, а конфиденциальные параметры вынесены в отдельный конфигурационный файл.
